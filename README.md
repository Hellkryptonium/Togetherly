# Togetherly

Togetherly is a university-focused platform designed to help students connect, collaborate, and learn from each other based on their skills and interests.

## 🚀 Features

* Student profiles and skill discovery
* Connect with students based on skills and interests
* Peer-to-peer collaboration
* Skill sharing and learning
* University-focused community

## 🛠️ Tech Stack

**Frontend**

* React
* Typescript

**Backend**

* Node.js
* Express.js

**Database**

* PostgreSQL

**DevOps**

* Docker
* GitHub
* CI/CD

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Hellkryptonium/Togetherly.git
cd Togetherly
```

### 2. Configure environment variables

Create the required environment files based on the provided examples:

```bash
cp .env.example .env
```

Add your local configuration and secrets to `.env`.

> Never commit `.env` files or other secrets to GitHub.

### 3. Install dependencies

Follow the setup instructions inside the `frontend` and `backend` directories.

### 4. Run the project

Start the required services and development servers according to the project's setup.
